**Descripción**

Se implementó el nuevo componente `Heading` siguiendo la nueva arquitectura del Design System bajo `components/features/ui/ln/heading`. Esta tarea incluyó una refactorización profunda para desacoplar la lógica de encabezados y links en utilitarios comunes, permitiendo su reutilización tanto en los nuevos componentes de UI como en los componentes legacy.

Se resolvió un bloqueo crítico de SSR mediante la implementación de un parseador HTML seguro y nativo, y se optimizaron los componentes siguiendo los principios SOLID, KISS y DRY.

**Detalle Técnico y Justificaciones**

### 1. SSR-Safe HTML Parsing (`parseHelper.js`)

Se introdujo un utilitario local `parseHelper.js` para reemplazar `html-react-parser`.

- **Motivo**: La librería original causaba un `ReferenceError: window is not defined` en el entorno Node.js de ARC.
- **Solución**: Se utiliza `node-html-parser` (ya presente en el proyecto) para transformar HTML en elementos de React de forma segura, evitando por completo el uso de `dangerouslySetInnerHTML`.

### 2. Arquitectura y Nomenclatura (`Heading` vs `Subtitle`)

Aunque el ticket mencionaba "Subtitle", se optó por el nombre `Heading` para el componente de UI.

- **Justificación**: Es semánticamente más correcto (mapeo directo a tags h1-h6) y evita confusiones con el concepto de "bajada" o "subtítulo de nota". La estructura sigue estrictamente el patrón de **Clean Architecture** y las guías de `components/features/ui/README.md`.

### 3. Optimización del Facade `Link`

El componente `Link` fue refactorizado y posteriormente optimizado:

- **SOLID/KISS**: Se simplificó la resolución de `children` y se eliminaron abstracciones innecesarias (`classBuilder`). El código se redujo en un 26% manteniendo la misma funcionalidad.
- **DRY**: Utiliza el helper centralizado `generateProps` compartido con el componente legacy `com-link.jsx`.

### 4. Justificación de Cambio en Snapshot

Se detectó la adición de la clase `com-text` en el snapshot de `Link`.

- **Razón**: Es el comportamiento esperado al integrar `generateProps`. Cuando un Link se usa sin la prop `link` (solo con `href`), el helper genera `com-text` para mantener la compatibilidad con los estilos legacy.
